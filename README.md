## Installation Instructions

The latest version of the system can be installed through the in-app **System Browser** by searching for **"Draw Steel"**.

You can also install it using any of the following alternative methods:

1. Paste the following URL into the **Install System** dialog found under the **Setup** menu of Foundry VTT:
   
https://raw.githubusercontent.com/MetaMorphic-Digital/draw-steel/refs/heads/main/system.json

2. Visit the repository’s [Releases](https://github.com/MetaMorphic-Digital/draw-steel/releases) page, where you can copy a `system.json` link for use in the Install System dialog.
